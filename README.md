# Cube ROI Calculator

Website: https://sugaryummy.github.io/cube-roi-calculator/

Finds which item gives you the most Final Damage per Bright Cube (or Glowing Cube).

## How to use
1. In Maple Scouter, open **Stat Efficiency**, then **Detail Eff.**
2. Type the amount and Final Damage % for each row into the site.
3. Set each item's level and its 3 potential lines.
4. Cube the item at the top of the list first.

Your setup saves in your browser. Use **Copy link** to share your gear with friends.

## Notes
- All items count as Legendary.
- Bright Cube uses Black Cube odds, Glowing Cube uses Red Cube odds (Nexon's published rates, data via brendonmay's cubing calculator).
- Lv 160+ items get +1% on Stat, All Stats and ATT lines.
